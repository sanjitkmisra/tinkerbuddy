TinkerBuddy privacy policy

Last updated 2026-11-26. TinkerBuddy is an independent product, not affiliated with or endorsed by Autodesk. Tinkercad is a trademark of Autodesk, Inc.

TinkerBuddy is a browser extension that coaches people while they design in Tinkercad. It is made for children aged about 8–14, used with a parent or at school, so we collect as little as possible and never sell or advertise.

The short version

  • No accounts, names, email addresses or passwords from children.
  • We never store what a child types or says, TinkerBuddy's answers, or pictures of their design.
  • A parent or teacher sees learning progress only if the child enters their family or class code.
  • No advertising, no tracking across websites, no selling or renting of data, no AI training on children's data.

What is sent when a learner asks for help

To answer, TinkerBuddy sends to its server: the question text and the last few lines of the conversation; a short text description of the Tinkercad editor (which buttons are on screen, how many shapes are selected); the learner's project plan for the open design (for example "LEGO body: holes underneath"); and, only if workspace pictures are allowed and only when needed (a question about how the design looks, or checking a step that can't be checked from the editor's buttons), one picture of the Tinkercad tab — never other tabs.

The server passes this to an AI model provider to produce the answer and returns it. The server does not store questions, answers or pictures. It keeps a random install number with a daily count and cost of answers, to enforce spending limits.

Voice: if the learner presses the talk button, the browser's own speech recogniser turns their voice into text (Chrome sends that audio to Google, Edge to Microsoft, under the browser's privacy terms). TinkerBuddy only ever receives the text. Teachers and parents can switch voice input off.

Classes and families (only with a code)

A teacher or parent can create a class or family and give the learner a short code to type into TinkerBuddy's Settings. Only then, TinkerBuddy also sends learning moments to that adult's private dashboard: that a question was asked, a hint was used, a step was checked, a project part was finished, and which skill was practised (for example "Aligning shapes: on their own"), with the time. It never sends what the learner typed or said, the answers, or pictures. The learner may add a nickname or initials so the adult can tell children apart; real names are not needed.

The adult can rename or remove a learner, set daily AI limits, pause AI answers, and switch voice input and workspace pictures off. The learner can leave at any time (Settings → Leave), which stops sharing at once. Learning moments are deleted automatically after 90 days; daily spending records after 400 days.

Adults who create a class or family do not give us their name or email either: they receive a private dashboard code. Keep it safe — anyone with it can see that class's dashboard.

Children, parents and schools

We do not knowingly collect personal information from children beyond what is described here. For school use, the school acts on parents' behalf for this educational purpose (as permitted under COPPA) and stays in control of student data; we use it only to provide TinkerBuddy to the school, under the school's direction, and will sign a student data privacy agreement on request. For home use, the parent sets up the family and can see and delete what is kept.

To delete data: remove the learner from the dashboard, leave the class in Settings, or uninstall the extension (which deletes everything stored on that computer). To have server records deleted sooner, write to Sanjit@catalystlogic.ai with the class or family code; we act within 30 days.

What stays on the computer

Settings, skills progress, project plans and the last few conversation lines are stored in the browser's extension storage on that computer only. Remove the extension, or use Settings → Reset progress, to delete them.

Security

All traffic is encrypted (HTTPS). AI keys are held only on the server. Dashboard codes are stored only as one-way hashes. Database access is limited to the server. If we learn of a breach affecting a class or family, we will tell the adult who created it and, for schools, the school, without undue delay.

Changes

If this policy changes in a way that matters, we will update the date above and say so in the extension before the change applies. Questions: Sanjit@catalystlogic.ai.
